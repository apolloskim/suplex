# suplex

Agent-driven lead scraping, enrichment, and email verification.

## Install

```bash
pip install suplex-ai
```

## Quick start

```bash
suplex setup      # configure API keys
suplex doctor     # check health
suplex plan "B2B SaaS for restaurants" --execute
suplex verify
suplex leads --status valid
```

See [AGENTS.md](AGENTS.md) for full documentation.
